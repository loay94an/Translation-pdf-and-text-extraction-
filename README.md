# مركز PDF والاستخراج والتحكم المركزي

هذا المستودع يجمع مشروعين مترابطين:

- **موقع ترجمة واستخراج PDF:** `apps/control-center/`
- **مركز التحكم لأندرويد وTermux:** `apps/control-center/mobile-agent/`
- **محركات استخراج المراجع وOCR والبيانات المنظمة:** `extraction/`

ابدأ من [دليل المشاريع بالعربية](PROJECTS-INDEX-AR.md) أو [دليل التشغيل السريع على Android](apps/control-center/mobile-agent/QUICKSTART-AR.md).

## حالة التحقق

- بناء واجهة PDF باستخدام Vite: ناجح.
- فحص Python واختبارات استخراج البيانات المنظمة: ناجح.
- فحص وكيل Termux ومسارات محركات الاستخراج: ناجح.
- بناء APK لأندرويد: ناجح، وتم رفع ملف `control-center-debug-apk` كـ GitHub Actions Artifact.

لم يتم نشر الموقع بعد. إعدادات GitHub Pages التلقائية معطلة مؤقتًا حتى لا يُنشر مستودع المصدر بدل واجهة الموقع المبنية. تم بناء APK تجريبي بنجاح، لكنه لم يُختبر بعد على هاتف Android فعلي.

> لا يحتوي هذا المستودع على كتب PDF الأصلية أو صور الصفحات أو نصوص OCR الكاملة. تبقى هذه المواد في مساحة عمل خاصة.

# تطبيق Android — مركز التحكم

تطبيق Android أصلي تأسيسي بـ Kotlin وJetpack Compose، يستخدم Chrome المثبت ولا ينشئ متصفحًا بديلًا.

## الوظائف المضافة
- فتح الروابط في Google Chrome مع fallback للمتصفح الافتراضي.
- استقبال النصوص والروابط والملفات من Android Sharesheet وIntents.
- استيراد ملفات النصوص وMarkdown وCSV وJSON.
- استخراج نص PDF النصي حتى أول 40 صفحة باستخدام PDFBox-Android.
- حفظ نسخة من الملفات المستلمة في Downloads/ControlCenter على Android 10+، بحد 50MB للملف.
- الاتصال بخادم Termux على 127.0.0.1:8765 باستخدام Bearer token.
- حفظ رمز Termux مشفرًا بـ AES-GCM ومفتاح محفوظ في Android Keystore.
- فحص الاتصال وتشغيل أوامر Linux صريحة من المستخدم عبر /api/exec.
- إرسال النص المستورد إلى النموذج المحلي عبر /api/chat.
- مشاركة نتيجة التحليل إلى تطبيق آخر.

## إعداد Termux (مرة أولى)

في Termux:
```bash
pkg update -y
pkg install -y nodejs-lts
termux-setup-storage
```

نزّل مجلد mobile-agent إلى الهاتف، ثم شغّل:
```bash
cd /مسار/المشروع/mobile-agent
bash start.sh
```

سيظهر رمز Bearer في سجل Termux. انسخه إلى خانة «رمز Termux» في التطبيق واضغط «اختبار الاتصال وحفظه». يحفظ التطبيق الرمز محليًا بصورة مشفرة؛ لا تحتاج إلى إعادة إدخاله عادةً ما دام ملف الرمز في Termux لم يتغير.

يجب أن يعمل خادم النموذج المحلي على:
```
http://127.0.0.1:8080/v1
```
ويمكن ضبط LOCAL_MODEL_BASE_URL وLOCAL_MODEL_NAME عند تشغيل agent.mjs.

## معالجة PDF المصوّر وOCR

يستخرج التطبيق النص الموجود فعليًا داخل PDF. إذا كان الملف صفحات مصورة، قد تكون نتيجة PDFBox فارغة؛ عندها يستخدم OCR في Termux على النسخة التي يحفظها التطبيق:
```bash
ls -lh ~/storage/downloads/ControlCenter
```
يمكن بعد ذلك تشغيل أدوات Poppler وTesseract وسكربتات مشروع المكتبة على الملف. يلزم إعداد صلاحية التخزين عبر termux-setup-storage.

## تشغيل خادم Termux تلقائيًا

يمكن إعداد بدء الخادم عند إقلاع الهاتف مرة واحدة:
1. ثبّت تطبيق Termux:Boot من مصدر Termux نفسه.
2. افتح Termux:Boot مرة واحدة.
3. من مجلد المشروع في Termux شغّل `bash install-boot-start.sh`.
4. اسمح لـTermux بالعمل في الخلفية، واضبط البطارية على عدم تقييد Termux وTermux:Boot.

سيبدأ خادم `agent.mjs` تلقائيًا بعد الإقلاع، ويُحفظ سجل بدء التشغيل في `~/.config/mobile-terminal-bridge/boot-agent.log`. يحتوي السجل رمز الاتصال السري؛ لا تشاركه. هذا إعداد اختياري يعتمد على سماح الشركة المصنّعة للهاتف بتشغيل خدمات الخلفية.

## البناء والتحقق

- Android Gradle Plugin 8.7.3، Kotlin 2.0.21، JDK 17، Android SDK 35.
- بناء APK آليًا عبر GitHub Actions في workflow: android-control-center-build.yml.
- ملف APK الناتج يُرفع كـ artifact باسم control-center-debug-apk عند نجاح التشغيل.
- لم يُؤكد نجاح البناء أو اختبار الجهاز حتى تظهر نتيجة Actions خضراء.

## ما لم ينفذ بعد
- تسجيل الدخول الرسمي إلى ChatGPT عبر SIWC؛ لا يتم استخدام WebView أو Chrome cookies أو جلسة تطبيق ChatGPT.
- ربط النموذج المحلي يعمل عبر جسر Termux بعد تشغيله وإدخال رمزه، لكنه لم يُختبر على الهاتف بعد.
- OCR المباشر داخل التطبيق غير مدمج؛ النسخة المشتركة تحفظ في Downloads ليعالجها Termux.
- لا توجد بعد واجهة طرفية TTY تفاعلية؛ أوامر /api/exec تنفذ أوامر غير تفاعلية بصلاحيات مستخدم Termux.
- لا يوجد APK موقع للإصدار النهائي أو نشر على المتجر.

## الأمان والخصوصية
- لا يقرأ التطبيق سجل Chrome أو كلمات المرور أو ملفات تعريف الارتباط أو جلسة ChatGPT.
- لا تُرسل الملفات إلى ChatGPT تلقائيًا.
- لا ينفذ التطبيق أوامر النموذج المحلي تلقائيًا؛ تنفيذ الأوامر يتطلب إدخال المستخدم والضغط الصريح.
- خادم Termux يستمع إلى 127.0.0.1 فقط؛ لا تعرضه على الشبكة أو الإنترنت.
- الأوامر تعمل بصلاحيات مستخدم Termux وليست معزولة بالكامل. راجع الأوامر قبل تنفيذها.

مرحبًا. اختر نموذجًا محليًا. يمكنك طلب تحليل النص أو إعداد خطة معالجة. أي أمر طرفية مقترح سيحتاج مراجعتك قبل تشغيله.

دليل الاستخدام

خطوات تشغيل الأدوات وحدودها الحالية

1. تهيئة Termux وربط التطبيق

انسخ الأمر التالي كاملًا والصقه في Termux. يثبت الأدوات الأساسية، يهيئ التخزين المشترك، ثم ينزّل فرع العمل ويشغّل الجسر.

pkg update -y
pkg install -y nodejs-lts git
termux-setup-storage
mkdir -p "$HOME/storage/shared/ControlCenterWorkspace"
cd "$HOME"
git clone -b feature/pdf-page-export-local-model-chat --single-branch https://github.com/loay94an/Translation-pdf-and-text-extraction-.git
cd Translation-pdf-and-text-extraction-/apps/control-center/mobile-agent
bash start.sh

إذا كان المستودع موجودًا مسبقًا، انتقل إلى مجلد mobile-agent وشغّل bash start.sh بدل إعادة استنساخه.

2. استخراج رمز الربط

عند التشغيل يظهر السطر Token في Termux. انسخ القيمة كاملة والصقها في خانة رمز الاتصال في الإعدادات، ثم اضغط اختبار الاتصال. إذا فقدت الرمز، يمكنك عرضه مجددًا من Termux بالأمر التالي:

cat "$HOME/.config/mobile-terminal-bridge/token"

الرمز سرّي ويمنح صلاحية تشغيل أوامر Termux. لا ترسله في محادثة عامة ولا تضعه في GitHub. عند الاشتباه بتسربه، أوقف الجسر وأعد إنشاء الرمز بحذف ملف token ثم أعد تشغيل الجسر.

3. تهيئة التخزين للكتب الكبيرة

termux-setup-storage
mkdir -p "$HOME/storage/shared/ControlCenterWorkspace"
LOCAL_AGENT_WORKSPACE="$HOME/storage/shared/ControlCenterWorkspace" bash start.sh

المساحة المشتركة تستفيد من المساحة المتاحة على وحدة التخزين الأساسية. إذا كان لديك تخزين خارجي، لا بد أن يكون مسارًا يستطيع Termux الوصول إليه. التطبيق لا يخلق سعة إضافية ولا يتجاوز المساحة الفعلية المتاحة.

4. إعداد الاستخراج

pkg install poppler tesseract python
tesseract --list-langs

تأكد من ظهور ara وeng. ابدأ بعينة صغيرة واضبط DPI واللغات قبل معالجة ملفات كبيرة.

5. إعداد النموذج المحلي

شغّل خادم OpenAI-compatible على المنفذ 8080 أو عدّل LOCAL_MODEL_BASE_URL في بيئة الجسر، ثم حدّث قائمة النماذج.

6. الأمان والتكامل

المتصفح الخارجي لا يُقرأ تلقائيًا. شارك النصوص صراحة. لا تنفذ أوامر النموذج تلقائيًا. لا ترفع ملفات الكتب أو OCR الخام إلى مستودع عام.

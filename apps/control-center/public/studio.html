سياق العمل

يمكن إرسال نص الصفحة الحالية أو النص الذي استوردته من المتصفح إلى النموذج المحلي لتحليله. لا تتم مشاركة الملفات تلقائيًا.

مرحبًا. اختر نموذجًا محليًا. يمكنك طلب تحليل النص أو إعداد خطة معالجة. أي أمر طرفية مقترح سيحتاج مراجعتك قبل تشغيله.
النموذج المحلي لا يملك وصولًا تلقائيًا للمتصفح أو ملفات الجهاز. التطبيق يمرر له فقط النصوص والسياق الذي تختاره، ويعرض الاقتراحات قبل أي تنفيذ.

دليل الاستخدام

خطوات تشغيل الأدوات وحدودها الحالية

1. تشغيل الجسر

cd /path/to/mobile-agent
bash start.sh

احتفظ برمز الاتصال الظاهر في Termux، ثم أدخله في الإعدادات واضغط اختبار الاتصال.

2. إعداد الاستخراج

pkg install poppler tesseract python
tesseract --list-langs

تأكد من ظهور ara وeng. ابدأ بعينة صغيرة واضبط DPI واللغات قبل معالجة ملفات كبيرة.

3. إعداد النموذج المحلي

شغّل خادم OpenAI-compatible على المنفذ 8080 أو عدّل LOCAL_MODEL_BASE_URL في بيئة الجسر، ثم حدّث قائمة النماذج.

4. الأمان والتكامل

المتصفح الخارجي لا يُقرأ تلقائيًا. شارك النصوص صراحة. لا تنفذ أوامر النموذج تلقائيًا. لا ترفع ملفات الكتب أو OCR الخام إلى مستودع عام.
